# Contextual errors

Failures in agreement creation, negotiation, amendments, delivery uploads, and decisions are shown beside the relevant action with an accessible `role="alert"` region. The dedicated evidence-review message remains below the corresponding AI button. App-wide connectivity/initialization failures may still appear in the page-level notice.

The update does not reset or increase Meta API usage limits and does not retry failed calls. Only the local database administrator can reset a daily allowance intentionally. User-facing errors never imply that rejected work was accepted.
